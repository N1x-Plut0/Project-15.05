# Project 15.05

A Japanese crossword (nonogram) game with a mobile-friendly interface in the style of Japanese paper and ink.

## Features

- Play pre-built levels inspired by Ghibli and Ukiyo-e
- Create and save custom levels
- Mobile-responsive design
- Local storage for custom levels

## Getting Started

Open `index.html` in your web browser to start playing.

## How to Play

Each row and column contains numbers indicating the length of consecutive filled cells. Fill the grid using the clues to reveal the hidden image.

- Use the "Fill" tool to color cells
- Use the "Mark as empty" tool for cells that should be blank
- Check your solution with the "Check" button
- Reveal the solution if needed
